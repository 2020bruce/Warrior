# 魂类战斗

在魂类项目中做战斗决策和实现时使用本 Skill。涉及引擎细节时，继续加载 GAS、角色移动、输入、动画、AI 或 C++ Skill。

## 必要手感

- 输入必须在明确且较短的窗口内缓存。
- 每个攻击都定义起手、判定、后摇、取消和无敌窗口。
- 翻滚无敌帧、体力消耗、后摇和方向必须是显式数据。
- 敌人攻击必须可读，并具有明确的追踪上限。
- 削韧和受击反应必须确定、可调。
- 命中停顿、镜头反馈、VFX 和音频必须强化同一套时序。
- 锁定必须稳定，支持切换目标，并正确处理镜头碰撞。
- 死亡、检查点、资源恢复和重试时间必须足够快，保持战斗节奏。

## 数据规则

- 时序以帧数或秒数存储在 DataAsset、曲线或表格中。
- 避免在 Tick 或 Blueprint 图中重复出现无法解释的魔法数字。
- 每个攻击都明确伤害类型、格挡交互、弹反交互、霸体和打断策略。
- 考虑多人前先定义权威和预测方案。

## 实现边界

- 高层动作状态属于战斗组件或能力层。
- 动画通知负责承接命中和无敌窗口。
- 加入多人后，伤害应用由服务器权威决定。
- AI 只负责选择动作，不拥有逐帧战斗真值。

## 验证

至少测试一次普通命中、格挡命中、成功翻滚穿过攻击、失败翻滚、体力耗尽、削韧破防和敌人死亡。记录时序和日志证据。在项目目标帧率下测试战斗，并检查镜头与动画过渡。

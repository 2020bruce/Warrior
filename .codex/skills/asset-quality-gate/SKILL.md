# 资产质量门禁

资产制作不是 Agent 退出成功就完成，而是必须先通过独立质量门禁。

## 标准流程

```text
制作
→ 文件与结构验证
→ Blender 几何检查
→ FBX 往返验证
→ 多视角渲染
→ 视觉评审
→ 有限轮次自动优化
→ 用户验收
→ UE 导入
```

任何一个技术硬错误都禁止暂存或导入。视觉评分不足时，优先根据结构化问题定点优化；达到最大轮次后交给用户复核。

## 技术门禁

以下情况必须阻断：

- `.blend`、FBX 或预览缺失、为空或无法读取。
- 没有有效顶点、面、UV 或材质槽。
- 非流形边、零面积面或游离顶点数量大于零。
- FBX 往返导入失败，或往返尺寸与源文件明显不一致。
- 尺寸为零、单位明显错误或导出对象数量不符合验收标准。
- 验收标准允许独立眼球、牙齿、舌头或可分离头部时，必须检查主体连通性和允许对象清单，
  不能简单要求整个文件只有一个网格对象。
- 达不到最低多视角预览数量。

变换未应用、材质槽过多、部件距离主体表面过远等问题至少记为质量警告；严重漂浮或穿插必须记为高严重度问题。

## 视觉门禁

视觉评审必须同时查看正面、侧面、背面、三分之四和脸部/关键细节视图。

建议评分项：

- 轮廓 0-5
- 比例 0-5
- 必需结构 0-5
- 表面贴合 0-5
- 材质表现 0-5
- 可读性 0-5

默认视觉通过线为 80 分。低于通过线时输出可执行的 `fix`，不得只写“继续优化”。

如果当前模型不支持图片输入，报告必须是 `visual-review-unavailable`。不得把文件存在、日志无报错或几何数据当作视觉通过。

## 自动优化

- 只修改现有资产，不重新盲目生成。
- 可修复的技术硬失败、视觉高严重度问题和 `block` 必须进入自动修复循环，不得在首轮直接失败。
- 自动修复 Agent 应复用当前资产会话，修改后重新执行完整门禁。
- 每轮先保存当前产物快照和后验报告。
- 每轮最多处理高价值问题，避免无边界重构。
- 默认最多两轮自动优化。
- 后一轮分数下降时保留前一轮最佳版本，不覆盖已确认资产。
- 达到最大轮次仍有高风险问题时，状态设为 `ready-for-review`，等待用户决定。

## 人工复核

- `ready-for-review` 必须在 Studio 资产页查看多视角预览和结构化问题。
- 提交修改意见时复用原 Agent 会话，不得从零重建。
- 人工通过必须记录复核说明。
- 存在技术硬失败时不允许人工覆盖。

## Studio 配置

```json
{
  "assetQuality": {
    "enabled": true,
    "minimumScore": 80,
    "maxOptimizationRounds": 2,
    "previewWidth": 640,
    "minPreviewViews": 5,
    "visualReview": {
      "enabled": true,
      "required": true,
      "command": "codex",
      "args": [],
      "model": "",
      "timeoutSeconds": 300
    }
  }
}
```

只有 `required=false` 时才允许在视觉评审不可用的情况下仅依赖技术规则；默认仍建议保留强制执行，以免低质量资产静默进入 Unreal。

## 结果记录

每次质量检查保存在：

```text
Saved/SoulForgeStudio/asset-productions/<作业 ID>/quality/
├─ latest.json
└─ round-<轮次>/
   ├─ quality.json
   ├─ blender-check.log
   ├─ visual-review.log
   ├─ visual-review.json
   ├─ views/
   └─ 当前轮次资产快照
```

这些记录属于本地生产证据，不替代 Git 中的源资产或验收记录。

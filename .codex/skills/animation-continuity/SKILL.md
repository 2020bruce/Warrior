# Unreal 动画连续性

当任务涉及攻击动画、连段、Montage、动画重定向或动画蓝图过渡时使用本 Skill。
连续性由 CLI 门禁判断，不依赖 Agent 主观描述。

## 工作流

1. 读取项目 `.soulforge/animation.json`。
2. 运行 `soulforge animation check --json`。
3. 读取报告中的 `assetPath`、`bone`、`frame`、角度和位移值。
4. 只修复报告中超过阈值的局部问题。
5. 重新运行同一命令，直到门禁通过。
6. Studio 会在战斗或动画任务中自动附加 `animation-continuity` 证据。

## 判定范围

- 动画序列内逐帧旋转和位移跳变。
- 相邻连段末帧与下一段首帧的局部姿态差。
- 骨架一致性。
- 关键帧、采样帧、时长和可采样骨骼是否有效。

`VB ` 开头的 Unreal 虚拟骨骼默认排除。需要检查时通过策略显式调整
`ignoredBonePrefixes`。

## 修复原则

- 不改角色运行时输入和伤害真值来掩盖动画跳变。
- 优先修正动画首尾姿态、根骨、骨盆和主要肢体，不盲目重做整段动画。
- 不通过放宽阈值让已知问题静默通过。
- 调整阈值必须说明项目动画风格、混合时长和验收依据。
- 门禁通过后仍需试玩确认节奏、可读性和手感。

## 边界

该门禁不能证明动作构图、表演质量或打击感优秀。它只保证可测量连续性，
避免模型或 Agent 生成明显跳帧、姿态断裂和错误骨架后被静默当成完成。

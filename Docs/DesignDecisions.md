# 设计决策

## 记录规则

记录会影响多个系统的设计决定、替代方案和后果。

## 决策

- 使用 Unreal Engine 5.8 和现有 `Warrior` 运行时模块开始垂直切片。
- 默认只做单人魂类体验，不在首版引入多人权威和复制复杂度。
- 战斗时序优先数据驱动，C++ 提供稳定运行时 API。
- Blueprint 负责内容组合和表现，不承载唯一的战斗真值。
- Git LFS 管理 Unreal、Blender、纹理、音频和视频资产。
- SoulslikeForge 保持为外部套件，游戏仓库不复制套件核心实现。
- 本机引擎、Blender、MCP 和 CLI 配置不进入版本控制。
